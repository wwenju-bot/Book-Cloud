# 小说自动化创作平台 · 开发排期计划（按周）

> **使用说明**：本文档负责回答"第几周做什么、什么时候能看到里程碑"，是 `docs/开发路线图.md`（回答"具体怎么做，到类/接口级别"）的排期层。两者配合使用：本文档每周任务后面标注了对应路线图章节号（如 `1.1-1.4`），需要具体实现细节时翻到路线图对应章节查。
>
> **排期假设**：按"1 人 + AI 辅助编码（AI 写主体代码，人工把关审核/联调/测试）"的节奏估算，仅供计划与追踪进度用，不是严格承诺工期。跑完第 1-2 周实际进度后，建议回头校准后续周数（AI 辅助下阶段1通常是节奏最准的参照系）。若是多人协作，阶段2开始可并行拆分给不同的人/AI 会话，相应压缩周数。
>
> 每周任务前的 `[ ]` 可在实际开发中勾选为 `[x]`，作为进度追踪。
